# Daily Sales & Support Desk: knowledge base

The daily desk agent reads these files before it writes the morning brief. Edit them in plain English. The agent follows what's here.

| File | What it holds |
|---|---|
| `plans.md` | Plans, prices and price-change dates. The only source of price facts. |
| `faq.md` | Approved answers to buyer questions. Support drafts may only use these. |
| `voice.md` | How Noor writes, and the rules every draft must follow. |
| `templates.md` | WhatsApp starting points by plan × temperature, plus follow-ups. |
| `reels-log.md` | Reel ideas already suggested or posted, so ideas don't repeat. |

Everything the agent produces is a draft. Noor approves every message before it is sent.
