Write your notes

10 minutes · in your phone's notes app

AI can only write about you from what you give it. Fill this in first — short answers are fine. Don't worry about making it sound good; that comes in step 4.

Your profile notes
Name: [YOUR NAME]
What I do: [ROLE, e.g. QA engineer at a product company]
City: [CITY]
What I want to be known for, in one line: [e.g. I make software releases calm and predictable]
3 skills: [SKILL 1], [SKILL 2], [SKILL 3]
3 things I've done (projects, results, certificates):
1. [THING 1, with a number if you have one]
2. [THING 2]
3. [THING 3]
Email: [EMAIL]
WhatsApp (with 91): [91XXXXXXXXXX]
LinkedIn: [LINKEDIN URL or leave blank]
Tip: numbers make a profile believable. "Cut regression testing from 3 days to 1" beats "worked on testing".
2

Run the build prompt

5 minutes · in Claude or ChatGPT

  1. Open claude.ai or chatgpt.com (free account is fine) and start a new chat.
  2. Copy the prompt below and paste it.
  3. Replace the line [PASTE YOUR NOTES HERE] with your notes from step 1. Send.
Build prompt
Build me a one-page personal portfolio website as a single HTML file.

About me:
[PASTE YOUR NOTES HERE]

Rules:
- One file only. All CSS inside a <style> tag. No frameworks, no external images. One Google Font is allowed.
- Mobile first: it must look great on a phone, then on a laptop.
- Sections, in this order: a hero with my name, role and one-line pitch; About; Skills; What I've done (as cards); Contact.
- Contact buttons: Email (mailto: link) and WhatsApp (https://wa.me/ link with my number).
- Clean and modern: plenty of white space, one accent colour, large readable text.
- Never invent facts about me. If something is missing, leave a clearly marked [placeholder].

Give me the complete code in one block. Then, in 3 short lines, tell me how to open it.
3

Open your website

5 minutes

In Claude

Claude shows the website as a live preview next to the chat. On the phone app, tap the preview card to open it full screen.

In ChatGPT

Type "Open this in canvas", then press Preview at the top of the canvas.

On a laptop (works with either)

  1. Copy the whole code block.
  2. Open Notepad (Windows) or TextEdit in plain-text mode (Mac) and paste it.
  3. Save it as my-site.html, then double-click the file. It opens in your browser.
Stuck? Paste this into the same chat: "I can't see the website. I'm on [phone / laptop] using [Claude / ChatGPT]. Give me the exact steps to open it."
4

Polish it with four prompts

20–30 minutes · same chat

Send these one at a time, and look at the preview after each one. This is the part where it starts to look like yours.

A · Make it look premium
Make the design look premium: more generous spacing, a subtle gradient behind the hero, softer card shadows and a gentle hover effect on buttons. Keep it one HTML file and keep all my text exactly as it is. Give me the full updated code.
B · Fix it for phones
Check the page at a 360px-wide phone screen. Fix anything that overflows sideways, any text smaller than 16px and any button smaller than 44px tall. List what you changed in one line each, then give me the full updated code.
C · Add your photo (or initials)
Add a round profile picture to the hero using this image link: [IMAGE URL — e.g. your LinkedIn photo link, or leave blank]. If the link is blank or doesn't load, show my initials in a coloured circle instead. Give me the full updated code.
D · Make the words sound like you
Rewrite all the text on the page so it sounds confident but not boastful, in simple English a recruiter or client can read in 30 seconds. Don't add any facts, numbers or skills I didn't give you. Give me the full updated code.
Didn't like a change? Say "Undo the last change and give me the previous version." AI is a draft partner — you're the editor.
